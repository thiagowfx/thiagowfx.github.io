For reasons out of scope of this post, I'm temporarily away from my Arch
ultrabook. I have a desktop which has been inactive for a while. It had
Elementary OS installed on it – I did that when the Freya version has been
launched, so I used it a little bit. However, after a few days, I simply wiped
it: elementary OS is way too buggy. There are several of them: its file manager
crashes randomly; the mouse cursor goes crazy sometimes; its music player
constantly lags. There are many of those small annoyances which makes the system
very irritating overall.

However, I must admit it is slightly more pleasant to use than, say, Ubuntu. The
elementary guys have a nice touch for UX and design. However, the team is way
too small, so I couldn't expect it to be a great distro. Anyway, I used it just
for inertia.

Now that it was been wiped, I installed debian jessie (8.1) on it. Curiously
enough, I never installed debian until today – even after trying out several
linux distros. Why not install Arch? Because this is not my main system, so I
don't want to spend all the time customizing it as I want. I simply want a
out-of-the-box working computer and a nice experience with it. I don't find it
reasonable to maintain two personal Arch systems: it tends to be more work than
necessary to achieve the perfect customization. Yes, I have dotfiles; yes, I
know how to synchronize packages; yet I don't like the idea of having two Arch
systems, it is just an opinion, not a technical limitation.

Mainly reason for me to hate debian is the out-of-dateness of its packages. But
as I said, I don't really care about this system, I just want to use it and
forget about the underlying software running on it. So I'm giving it a try for a
few days. I'll try not to enable the testing (sid) repos...

[Arch](https://wiki.archlinux.org/index.php/Arch_is_the_best) is still the best.
